# API Execution Guide

Use `configs/.env.example` as the variable checklist. Do not commit `.env` or credentials.

The recommended score-prioritized fresh profile is
`configs/profiles/fresh_authoritative_v4.yaml`: it uses
`deepseek-ai/DeepSeek-V4-Flash` at temperature 0 with the accepted Version 2
source-grounded processing. This is a global profile choice from completed
fresh evaluation aggregates, never a query-specific rule or evaluator input.
`deepseek-ai/DeepSeek-V3.2` with locked C1 context remains an experimental
Evidence-focused profile, not the default.

The transport failures occurred during a user-initiated transition from an explicit localhost proxy route to TUN-mode transparent routing. The causal runner was functional. Network completion rates across conditions are therefore not treated as model-quality evidence.

The causal runner keeps TLS verification enabled and labels post-TUN recovery calls as `POST_TUN_NETWORK_RECOVERY`.
