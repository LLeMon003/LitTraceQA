# Profile Reference

Profiles live under `configs/profiles/`.

- `CACHED_EXACT_DEV`: deterministic replay of the accepted DEV checkpoint.
- `CACHED_EXACT_PRODUCTION`: deterministic production-safe replay.
- `HISTORICAL_FRESH_COMPATIBILITY`: the completed Version 2.3 fresh SiliconFlow path.
- `RECOMMENDED_FRESH_EXPERIMENTAL`: pilot-justified C1 plus stronger-model profile; it does not replace frozen Version 2.
- `FRESH_AUTHORITATIVE_V4`: the recommended blank-runtime-cache profile based on the disclosed global fresh-score comparison; it never guarantees a provider-generated score.
